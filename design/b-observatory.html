02 / PIPELINE

How a frame becomes a sound field

No LLM sits between NASA's data and your ear. Every number is computed and every label is traceable to a NASA sentence.

01

Extract

Still frames pulled from svs.gsfc.nasa.gov with the official description, alt text, credits and dataset list.

02

Analyse

OpenCV: 32 × 24 HSL grid, Sobel edge grid, connected components for the named structures.

03

Label

Objects matched to NASA's own sentences, then hand-reviewed. Unreviewed labels never ship.

04

Play

Web Audio in the browser: four persistent voices, 30 ms smoothing, a −12 dB limiter.

Accessibility is the product

Built to be driven without a screen.

The canvas is never the only way in. Every scene also exposes an object list — each entry plays its own sound and reads its own description — and the narrator's every line lands in a live region, so a screen reader and the sonification never talk over each other.
